# 🔮 ALCHEMY | Portfólio de Desenvolvedora

### Transformando ideias em soluções digitais, unindo tecnologia, criatividade e propósito.

Bem-vindo(a) ao **ALCHEMY**, meu portfólio pessoal de desenvolvimento de software.

Este projeto foi criado para apresentar minha trajetória, minhas habilidades e meus projetos por meio de uma experiência interativa inspirada no universo da alquimia, dos grimórios e das bibliotecas medievais.

A proposta é combinar desenvolvimento web moderno, animações e criatividade, sem deixar de lado a acessibilidade e a experiência do usuário.

## ✨ Funcionalidades

- Interface inspirada em bibliotecas medievais e alquimia.
- Navegação entre ambientes do portfólio.
- Animações e transições com Motion.
- Efeitos mágicos e interações com o cursor.
- Cenários com profundidade e parallax.
- Apresentação interativa dos projetos.
- Seção Sobre Mim com grimório encantado.
- Protótipo de livro tridimensional com abertura animada.
- Layout adaptável a diferentes tamanhos de tela.

### 📖 Grimório 3D

Uma das experiências em desenvolvimento no ALCHEMY é um grimório medieval interativo.

A proposta inclui uma chave mágica para desbloquear o livro, animação tridimensional da capa, páginas de pergaminho e capítulos que apresentam minha história.

O protótipo inicial utiliza **Three.js e React Three Fiber** para explorar geometria, câmera, iluminação e movimento tridimensional.

Os recursos mais avançados ainda estão em desenvolvimento.

## 💻 Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- Git

### 1. Clone o repositório

```bash
git clone https://github.com/KettlemDrobinheski/alchemy-portfolio.git
```

### 2. Entre na pasta

```bash
cd alchemy-portfolio
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor

```bash
npm run dev
```

Abra o endereço local exibido no terminal.

### Protótipo do grimório

Com o servidor iniciado, acesse:

```text
http://localhost:5173/grimoire-prototype.html
```

A porta poderá variar conforme o ambiente.
